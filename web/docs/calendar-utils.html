Calendar utilities

Whole months, liturgical seasons, Ge'ez numerals, and a calendar feed you can subscribe to without writing any code at all.

GET/v1/calendar/{year}/{month}

One Ethiopian month, fully described day by day, the right call for rendering a calendar view.

$ curl …/v1/calendar/2018/8
  • Months are 1–13. Months 1–12 have 30 days; Pagumen (13) has 5, or 6 in a leap year.
  • The response includes the localized month name, day count, the weekday the month opens on, and a complete date description for every day, fasting and feasts included.
GET/v1/calendar/season

The liturgical season a date falls in.

ParameterRequiredDefault
dateYes–
calendarNogregorian
 
$ curl "…/v1/calendar/season?date=2026-03-04"

Returns the season key, localized names, Gregorian and Ethiopian boundaries, total days, the day-within-season, and a theme key, a stable identifier apps can map to their own colours and imagery for season-aware UI.

GET/v1/calendar/geez-numeral
$ curl "…/v1/calendar/geez-numeral?number=2018"
{ "number": 2018, "geez": "፳፻፲፰" }

Ge'ez numerals have no zero; the endpoint accepts positive integers and rejects everything else with a clear 400. The implementation handles the classical ፻ (hundred) and ፼ (ten-thousand) composition rules, verified against fixture vectors.

GET/v1/calendar/ics

An iCalendar feed: the no-code integration path.

ParameterRequiredValues
yearYesEthiopian year
typeNoall, fasting, feasts
 
$ curl "…/v1/calendar/ics?year=2018&type=fasting" -o eotc-2018.ics

Paste the URL into Google Calendar ("From URL"), Apple Calendar, or Outlook and every fast or feast appears as an all-day event. The response is text/calendar and byte-deterministic: the same query always produces identical bytes, so the feed caches cleanly and diffs meaningfully.
