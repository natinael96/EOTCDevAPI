Gitsawe, readings & Sinksar

The date-level bridge between the Gitsawe lectionary (ግጻዌ), the Sinksar (ስንክሳር), and the Bible, with resolution semantics that say exactly what the API knows and doesn't.

GET/v1/gitsawe/{date}

The complete bridge for one date: fixed-cycle Gitsawe appointments, Sinksar summary metadata, the annual and monthly feast lists, and normalized Bible references.

$ curl "…/v1/gitsawe/2018-08-04?calendar=ethiopian"

Resolution semantics: read this first

The response currently reports:

{ "resolution": "fixed_candidate_only" }

This is an important, deliberate restriction. Only the fixed Gitsawe cycle is transcribed so far. On a Sunday or a movable feast, the printed source may appoint a different service order that takes precedence. Rather than pretending the fixed appointment always wins, the API tells you when it knows a conflict is possible:

{
  "coverage": {
    "fixedCycle": "transcribed",
    "movableCycle": "not_transcribed",
    "sundayCycle": "not_transcribed",
    "occasionalCycle": "not_transcribed",
    "bahireHasabTables": "not_transcribed"
  },
  "resolutionFactors": {
    "isSunday": true,
    "movableFeasts": ["fasika"],
    "knownPrecedenceConflict": true,
    "note": "Sunday and movable Gitsawe cycles are not yet transcribed; precedence is not resolved."
  }
}
Consumer rule. Respect fixed_candidate_only and knownPrecedenceConflict. Present the fixed appointment as "the appointed fixed-cycle reading", not as "today's service order", whenever a conflict is flagged.

Service structure

API keySource labelMeaning
matinsዘነግህMorning office
liturgyዘቅዳሴDivine Liturgy
vespersዘሠርክEvening office

Each service holds psalms, gospels, epistlesAndActs, and the appointed anaphora (ቅዳሴ, a chant name, not a Bible passage). Readings preserve the source and the normalized layer side by side:

{
  "sourceField": "ወንጌል",
  "alternate": false,
  "sourceBook": "ዮሐንስ",
  "bibleBook": "JHN",
  "sourceCitation": "ም· ፲ ቍ‧ ፩ ፳፪",
  "canonicalReference": {
    "book": "JHN", "chapter": 10,
    "verseStart": 1, "verseEnd": 22,
    "toEndOfChapter": false,
    "method": "printed_citation",
    "confidence": "probable"
  }
}

The source citation is never overwritten by normalization. alternate: true marks a reading the source introduces with ዓዲ ("again"): an additional or repeated appointment. Do not discard it just because another reading of the same type exists.

GET/v1/readings/{date}

The recommended endpoint when you need only the appointed Bible readings: no Sinksar entries, no source detail unrelated to reading selection. Acts is separated from the other epistles for easier rendering:

$ curl "…/v1/readings/2018-12-22?calendar=ethiopian"
{
  "date": { "gregorian": "2026-08-28", "ethiopic": "2018-12-22" },
  "source": { "cycle": "fixed", "resolution": "fixed_candidate_only" },
  "services": {
    "matins":  { "psalms": […], "gospels": […], "epistles": [], "acts": [], "anaphora": null },
    "liturgy": { … },
    "vespers": { … }
  },
  "bible": { "textIncluded": false, "license": "CC-BY-NC-ND-4.0" }
}
GET/v1/sinksar/{date}

The focused view of the day's Sinksar commemorations: the annual (ዓመታዊ) and monthly (ወርኀዊ በዓላት) lists without the full Gitsawe payload.

$ curl "…/v1/sinksar/2018-01-01?calendar=ethiopian"
{
  "date": { "ethiopic": "2018-01-01", "weekday": { … } },
  "annualFeasts": {
    "heading": "📌 መስከረም ፩ ቀን የሚከበሩ ዓመታዊ የቅዱሳን በዓላት",
    "items": [
      { "id": "1-1-annual-1", "title": "ርዕሰ ዓውደ ዓመት",
        "sourceText": "፩.ርዕሰ ዓውደ ዓመት" },
      { "id": "1-1-annual-2", "title": "ቅዱስ በርተሎሜዎስ ሐዋርያ", … }
    ]
  },
  "monthlyFeasts": {
    "heading": "📌 ወርኀዊ በዓላት",
    "items": [ { "title": "ልደታ ለማርያም ድንግል እግዝእትነ", … } ]
  },
  "entryCount": 9,
  "fullTextAvailable": false,
  "reason": "Full-text publication rights are not yet recorded."
}
FieldMeaning
headingThe original printed summary heading, unmodified
items[].idStable derived item ID (month-day-kind-n)
items[].titleNumber prefix removed, for display and search
items[].sourceTextThe original numbered source line, preserved exactly
entryCountTotal Sinksar entries recorded for the day

The compiler currently extracts 1,542 annual and 1,905 monthly feast items across the year. A day may legitimately lack one of the two lists; absence is a null heading and an empty items array, never an error.

The cycle collections¶

The movable and monthly lectionary layers are served as candidate reference data: browsable collections, not yet applied to date resolution. Every response carries resolution: "candidates_only" until the precedence rules that would pick a winner are reviewed. This is the stepping stone toward the full resolver.

GET/v1/gitsawe/seasons

The 43 movable-cycle entries, located by season and week rather than by fixed date: the Nineveh fast, the eight named Sundays of Great Lent (ዘወረደ through ሆሣዕና), the Resurrection-season Sundays, the Sundays of ክረምት, and the rest. Filter with ?season=abiyTsom (an unknown season returns the valid list). Each entry carries its season, week, part, title, provenance, and normalized reading references per service.

GET/v1/gitsawe/monthly

The 9 monthly Sunday rules: day-range, nth-Sunday, or cross-month spans (Meskerem 26 running into the next month), each with its መዝሙር chant identifier and readings. All entries carry appliesTo: "sunday"; applying a range rule to a weekday is a documented source-review issue, which is one reason resolution waits.

GET/v1/gitsawe/feasts

The feast graph in one response: 21 feasts, each with its sub-feasts (eve and morning services, numbered weeks of ጽጌ), and each sub-feast with its mahlet service orders summarized. Fixed feasts carry a dateKey; movable feasts carry none and are located liturgically.

GET/v1/gitsawe/mahlets/{id}

One ማኅሌት service order in detail: its titled sequence of chant roles (ነግሥ, ዚቅ, ወረብ, መልክዕ…) in liturgical order. Chant text is rights-restricted and stays out of the public runtime; the response carries the roles, the count, and the text policy, exactly like reading bodies elsewhere in the API.

$ curl …/v1/gitsawe/mahlets/st_abuye_tikmt_negs
{
  "id": "mahlet:st_abuye_tikmt_negs",
  "title": "ሥርዓተ ማኅሌት ዘጥቅምት አቡነ ገብረ መንፈስ ቅዱስ",
  "feast": { "id": "feast:st_abuye_tikimt" },
  "chants": [ { "role": "ነግሥ" }, { "role": "መልክአ ሥላሴ" }, { "role": "ዚቅ" }, … ],
  "chantTextAvailable": true
}

The Bible reference model¶

Canonical references use stable book IDs:

MAT MRK LUK JHN ACT ROM 1CO 2CO GAL EPH PHP COL
1TH 2TH 1TI 2TI TIT PHM HEB JAS 1PE 2PE 1JN 2JN 3JN JUD REV PSA
  • Context-aware resolution: a bare ዮሐንስ in a Gospel field is JHN; in an epistle list it is 1JN unless numbered otherwise.
  • Confidence is explicit: confirmed, probable, ambiguous, or unresolved. Most citation-only links are probable; do not present them as manually confirmed textual equivalence.
  • "To end of chapter": when the source says ፍጻሜ ምዕራፍ, the reference carries verseEnd: null, toEndOfChapter: true so the start verse is never misrepresented as the end.
Why no verse text? The available local editions (am-1980, gez-1980) are CC BY-NC-ND 4.0; this API is MIT. The API therefore serves references, structure, and citations, never the restricted text. Applications that display verse text must obtain a compatible edition and honour its attribution, noncommercial, and no-derivatives terms.
