Fasting & feasts

The API answers why, not just yes or no — which fast, how long it is, how far into it the date falls, and which rule produced the answer.

GET/v1/fasting/{date}

Fasting status for one date. Accepts ?calendar=ethiopian like every date endpoint.

$ curl …/v1/fasting/2026-03-04
{
  "jdn": 2461104,
  "gregorian": "2026-03-04",
  "ethiopic": "2018-06-25",
  "weekday": { "n": 3, "amharic": "ረቡዕ", "english": "Wednesday" },
  "isFasting": true,
  "reason": "ዓቢይ ጾም (Great Lent)",
  "weeklyFast": false,
  "fastFreeSeason": false,
  "feastOverride": false,
  "periods": [ { "key": "abiy_tsome", "dayOfPeriod": 17 } ]
}
FieldMeaning
isFastingThe final answer for the date, after all rules and exceptions
weeklyFastThe Wednesday/Friday rule is what applies
fastFreeSeasonWeekly fasting is suspended — the fifty days from Fasika to Pentecost (ሃምሳ)
feastOverrideA great feast of the Lord (Gena, Timket) overrides the weekly fast
periodsNamed fasting periods active on the date, with dayOfPeriod progress
The weekly fast is not absolute. Wednesdays and Fridays are fasting days — except during the fifty days of ሃምሳ, and except when a great feast of the Lord falls on one. Both exceptions are implemented and flagged, never silently applied. Regional practice varies for some minor rules; where reviewed sources disagree, the API does not claim one custom as universal.
GET/v1/fasts/{year}

All seven canonical fasting periods of an Ethiopian year — the answer to "when does Lent start this year?"

$ curl …/v1/fasts/2018

Each period includes:

  • a stable key (e.g. abiy_tsome, tsome_nebiyat);
  • Amharic, transliterated, and English names;
  • fixed or movable status;
  • duration in days;
  • start and end dates in both calendars;
  • a short description.

The response also states the weekly-fast rule itself, so a client can render the complete fasting picture from one call.

GET/v1/feasts/{year}

Every feast of an Ethiopian year.

ParameterDefaultValues
typeallall, movable, fixed
 
$ curl "…/v1/feasts/2018?type=movable"

Each feast carries a stable key, localized names, its movable/fixed marker, the resolved Gregorian and Ethiopian dates for that year, the weekday, and a major-feast marker where applicable. Movable feasts are located by Bahire Hasab; fixed feasts by the Ethiopian month/day.

Gena is not always January 7. Ethiopian year 2016 began on September 12, 2023 (2015 was a leap year), so every date until the following Gregorian leap day shifted by one: Tahsas 29 fell on January 8, 2024 — and Lalibela observed it there. Timket shifts identically. Popular sources hardcode January 7; this API returns the true calendar arithmetic, which is why /v1/feasts resolves dates per year instead of publishing a fixed Gregorian table.
